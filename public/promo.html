같은 폴더 자동 이어보기

선택한 이미지가 있는 폴더의 지원 이미지를 불러옵니다. ←/→ 키나 이전·다음 버튼으로 넘기세요.

100%는 화면 맞춤

세로 사진도 위아래가 잘리지 않도록 전체가 들어오는 크기를 100%로 표시합니다.

다음 이미지도 같은 배율

140%로 확대했다면 다음 이미지에서도 140% 유지. 이미지마다 100%로 초기화하지 않습니다.

실뷰 1.0.0 설치 파일 다운로드 ↓

Windows 64비트 · EXE 설치 파일 · 약 107 MiB · 2026.09.30

이미지 열기와 편집은 PC에서 처리하며 원본을 서버에 업로드하지 않습니다. 웹 버전과는 별도 앱이며, Windows 기본 이미지 앱은 설치 후 직접 선택해야 합니다.

지원 형식: JPG · JPEG · JFIF · PNG · GIF · WebP · BMP · AVIF · SVG · ICO
HEIC·TIFF는 이번 버전에서 지원하지 않습니다.

파일 확인 정보 (SHA-256) 90BF0635936952C78F29E66A9A8D31F163BB6965A0463294E2D0E7468FF47CDD
처음 한 번만 설정하세요

설치하고, 기본 이미지 앱으로

  1. 설치 파일 다운로드 → 실행위 버튼으로 실뷰 1.0.0 설치 파일을 내려받아 설치합니다. 바탕화면 또는 시작 메뉴에서 실뷰를 실행할 수 있습니다.
  2. 이미지 우클릭 → 연결 프로그램탐색기에서 PNG/JPG 파일을 우클릭한 뒤 연결 프로그램 → 다른 앱 선택 → 실뷰 → 항상을 선택합니다. Windows 버전에 따라 ‘항상 이 앱을 사용’ 확인란으로 표시될 수 있습니다.
  3. 파일 형식별로 한 번씩 선택PNG와 JPG 등 자주 사용하는 형식을 각각 설정하세요. 앱의 파일 → 기본 이미지 앱 설정에서 Windows 설정을 열어 변경할 수도 있습니다.
  4. 이제 더블클릭으로 열고, 방향키로 넘기기한 장만 열어도 같은 폴더의 이미지 목록이 나타납니다. 실뷰가 이미 실행 중이면 기존 창에서 새 파일로 전환합니다.

‘실뷰’가 목록에 없다면 ‘PC에서 앱 선택’으로 설치 폴더의 실뷰.exe를 지정하세요. 현재 설치 파일은 코드 서명되지 않아 Windows에서 게시자 확인 경고가 표시될 수 있습니다. 출처가 이 상세페이지인지 확인하고, 보안 프로그램이 차단하면 실행을 중단하세요.

Windows 앱 메뉴 안내

익숙한 메뉴, 간단한 사용법

파일 → 이미지 열기
이미지 한 장을 선택하면 같은 폴더도 자동으로 불러옵니다. 상단 이미지 열기 버튼 또는 Ctrl + O를 사용할 수 있습니다.
파일 → 폴더 열기
폴더를 직접 골라 지원 이미지를 불러옵니다. Ctrl + Shift + O도 가능합니다. 업로드나 브라우저 폴더 권한 연결은 필요 없습니다.
편집 / 뷰어
모자이크, 도형, 화살표, 텍스트, 자르기 등 간편 편집을 사용합니다. 편집 이미지는 새 파일로 저장하며 열었던 원본 경로의 덮어쓰기는 막습니다.
라이브러리
같은 폴더에서 불러온 이미지 목록과 썸네일을 표시하거나 숨깁니다. 원하는 이미지를 클릭해 바로 이동하세요.
확대·축소 / 이전·다음
상단 +/− 버튼 또는 마우스 휠로 배율을 바꿉니다. 다음·이전 이미지에도 배율이 유지됩니다. ←/→ 키로도 넘길 수 있습니다.
다운로드 / 전체 다운로드
현재 이미지 또는 불러온 이미지 전체를 PC에 저장합니다. 전체 저장은 기존 파일과 이름이 겹치면 번호를 붙여 보존합니다.
파일 → 기본 이미지 앱 설정
Windows 기본 앱 설정을 엽니다. 설치 프로그램이 사용자의 기본 앱을 강제로 바꾸지는 않습니다.
닫기 / 모두 비우기
실뷰에 불러온 목록에서 이미지를 제외합니다. PC의 원본 이미지 파일을 삭제하는 기능이 아닙니다.
