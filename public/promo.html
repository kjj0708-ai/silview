사용 전에 궁금한 점

설치 방법과 앱 메뉴는 필요한 때 펼쳐보세요.

Windows 설치 및 기본 이미지 앱 설정은 어떻게 하나요?
  1. 설치 파일 다운로드 → 실행실뷰 1.0.0 설치 파일을 내려받아 설치합니다. 바탕화면 또는 시작 메뉴에서 실행할 수 있습니다.
  2. 이미지 우클릭 → 연결 프로그램탐색기에서 PNG/JPG 파일을 우클릭한 뒤 연결 프로그램 → 다른 앱 선택 → 실뷰 → 항상을 선택합니다. Windows 버전에 따라 ‘항상 이 앱을 사용’ 확인란으로 표시될 수 있습니다.
  3. 파일 형식별로 한 번씩 선택PNG와 JPG 등 자주 사용하는 형식을 각각 설정하세요. 앱의 파일 → 기본 이미지 앱 설정에서도 Windows 설정을 열 수 있습니다. 실뷰가 목록에 없다면 ‘PC에서 앱 선택’으로 설치 폴더의 실뷰.exe를 지정하세요.
  4. 더블클릭으로 열고, 방향키로 넘기기이미지 한 장만 열어도 같은 폴더 목록이 나타납니다. 앱이 이미 실행 중이면 기존 창에서 새 이미지로 전환합니다.

현재 설치 파일은 코드 서명되지 않아 Windows에서 게시자 확인 경고가 표시될 수 있습니다. 다운로드 출처가 이 상세페이지인지 확인하세요. 보안 프로그램이 차단하면 실행을 중단하세요.

Windows 앱 메뉴와 단축키를 알려주세요.
파일 → 이미지 열기
이미지 한 장을 선택하면 같은 폴더도 자동으로 불러옵니다. 상단 이미지 열기 버튼 또는 Ctrl + O를 사용하세요.
파일 → 폴더 열기
폴더를 직접 골라 지원 이미지를 불러옵니다. 단축키는 Ctrl + Shift + O입니다.
편집 / 뷰어
모자이크, 도형, 화살표, 텍스트, 자르기 등을 사용합니다. 편집 결과는 새 파일로 저장하며 원본 경로로 덮어쓰기는 막습니다.
라이브러리
같은 폴더의 이미지 목록과 썸네일을 표시하거나 숨깁니다. 이미지를 클릭해 바로 이동하세요.
확대·축소 / 이전·다음
상단 +/− 버튼 또는 마우스 휠로 배율을 바꿉니다. 이미지 전환 시 배율이 유지됩니다. ←/→ 키로 넘길 수 있습니다.
다운로드 / 전체 다운로드
현재 이미지나 전체 이미지를 PC에 저장합니다. 전체 저장은 기존 파일과 이름이 겹치면 번호를 붙여 보존합니다.
파일 → 기본 이미지 앱 설정
Windows 기본 앱 설정을 엽니다. 설치 프로그램이 사용자의 기본 앱을 강제로 바꾸지는 않습니다.
닫기 / 모두 비우기
실뷰 목록에서 이미지를 제외합니다. PC의 원본 파일을 삭제하는 기능이 아닙니다.
웹 버전도 이미지 한 장을 열면 폴더 전체를 보여주나요?

자동으로 같은 폴더를 읽는 기능은 Windows 설치형에서 제공합니다. 브라우저는 보안상 선택하지 않은 다른 파일을 마음대로 읽을 수 없습니다.

웹 버전에서 폴더 전체를 보려면 직접 폴더를 선택하거나 ‘폴더 열기·이어보기 연결’을 사용해야 합니다. 폴더 접근 권한과 연결 유지 여부는 브라우저에 따라 달라질 수 있습니다.

무료인가요? 이미지는 서버로 올라가나요?

Windows 설치형과 웹 버전 모두 무료이며 회원가입이 필요 없습니다. 이미지 보기와 편집은 사용하는 기기에서 처리합니다. 원본 이미지를 서버에 업로드하지 않습니다.

앱에는 제작자 소개 링크와 RSS가 있으며 해당 기능은 인터넷을 사용합니다. 사진을 가리는 팝업 광고나 추가 프로그램 끼워 넣기는 없습니다.

Windows 설치형은 원본 경로에 덮어쓰기를 막습니다. 편집 결과를 다른 이름이나 폴더에 저장하세요. 웹 버전의 편집 결과는 브라우저 다운로드로 저장됩니다.
